# AI Innocence Detection

This guide explains how JusticeMAP uses Google's Gemini AI to analyze parole hearing transcripts and detect potential innocence indicators.

## Overview

JusticeMAP performs AI-powered analysis of parole hearing transcripts to identify four types of signals:

1. **Explicit Claims** - Direct statements of innocence
2. **Contextual Signals** - Evidence-based indicators (alibi, coercion, misidentification)
3. **Implicit Signals** - Maintained innocence despite consequences
4. **Bias Language** - Institutional patterns that may indicate bias

## How It Works

### Step 1: Transcript Preprocessing

Before analysis, transcripts are preprocessed to:

- Remove line numbers (e.g. "1|", "2|", etc.)
- Normalize speaker labels (INMATE, DEFENDANT, PRESIDING, COMMISSIONER, etc.)
- Preserve original formatting for citation purposes
- Clean up common OCR errors from PDFs

**File**: `src/utils/transcriptPreprocessor.ts`

### Step 2: Intelligent Chunking

Transcripts are split into chunks while preserving speaker context:

- **Target chunk size**: 3000-4000 characters
- **Strategy**: Split at speaker boundaries, never mid-sentence
- **Context preservation**: Each chunk includes speaker identification
- **Overlap**: Minimal overlap to maintain continuity

**Why chunking?**
- Gemini has token limits
- Smaller chunks = faster processing
- Maintains speaker context for accurate analysis

**File**: `src/utils/transcriptChunker.ts`

### Step 3: AI Analysis with Gemini

Each chunk is analyzed by **Gemini 2.0 Flash Lite** using a specialized prompt that looks for:

**Explicit Claims** (0-30 points):
- "I didn't do it"
- "I'm innocent"
- "I wasn't there"
- "Someone else did this"

**Contextual Signals** (0-25 points):
- Alibi evidence with corroboration
- Coerced confession mentions
- False testimony or perjury
- Misidentification
- Evidence tampering
- Witness recantations

**Implicit Signals** (0-25 points):
- Refused plea deal despite long sentence
- Maintained innocence despite consequences
- Willing to take lie detector test
- Requests DNA testing or case review

**Bias Language** (0-20 points):
- "Lack of insight" (refusing to admit guilt)
- "Minimizing" (downplaying offense)
- "Not taking responsibility"
- "Denial"
- "Lack of remorse"

**File**: `src/services/gemini.ts`

**Function**: `analyzeChunkForInnocenceSignals(chunk, context)`

### Step 4: Exact Quote Validation

Every AI-detected signal must include:

- **Exact quote** from the transcript (verbatim)
- **Line number** (for TXT files)
- **Page number** (for PDFs)
- **Speaker identification** (who said it)
- **Confidence score** (0.0-1.0)

This ensures all findings are traceable to the source.

### Step 5: Result Aggregation

The analysis orchestrator combines results from all chunks:

- Deduplicates similar findings
- Ranks by confidence score
- Calculates overall innocence score (0-100)
- Stores in database for instant retrieval

**File**: `src/services/innocenceDetector.ts`

**Function**: `analyzeTranscriptForInnocence(transcriptId, onProgress)`

## Key Features

### AI-Generated Client Card Insights

Every client card displays a short, compelling sentence generated by AI:

**How it works:**
1. Extract first 3000 characters of transcript
2. Send to Gemini with specialized prompt
3. AI identifies the most compelling innocence indicator
4. Returns a short sentence (max 15 words)
5. Display on client card in italic styling

**Examples:**
- "Claims he was at work when crime occurred, has time cards"
- "States confession was coerced after 18 hours of interrogation"
- "Maintains innocence despite refusing plea deal that would release him"

**Loading strategy:**
- First 20 cards load on page load
- Remaining insights load in batches of 5
- Progressive display (no page blocking)
- Fallback to pattern matching if API unavailable

**File**: `src/services/gemini.ts`

**Function**: `extractKeyInnocenceIndicator(transcript)`

### Enhanced Pattern Matching

In addition to AI analysis, the system uses pattern matching to detect:

**15 Bias Language Patterns:**
- lack of insight, minimizing, denial, not taking responsibility, lack of remorse
- not suitable, unrealistic, superficial, not credible, manipulative
- danger to society, continues to pose risk, not rehabilitated, risk to public safety, unresolved issues

**12 Innocence Patterns:**
- didn't do, innocent, wrongly convicted, falsely accused, was not there
- someone else did, misidentification, actually innocent, false testimony, coerced confession
- alibi, recant

This ensures no signals are missed even if AI analysis is unavailable.

## API Configuration

### Gemini Model Selection

Current model: **gemini-2.0-flash-lite**

**Why this model?**
- Fast responses (2-4 seconds per chunk)
- High accuracy for text analysis
- Cost-effective (free tier: 15 requests/minute)
- Good at identifying nuanced language patterns

**Alternative models** (configured in code):
- `gemini-1.5-pro` - More accurate but slower
- `gemini-2.0-flash` - Balanced speed and accuracy

### Rate Limiting

To avoid hitting API limits:

- Built-in 2-second delay between chunks
- Batch processing for multiple transcripts
- Progress callbacks for user feedback
- Retry logic for transient failures

**Free tier limits:**
- 15 requests per minute
- 1,500 requests per day
- ~50 transcript analyses per day

### Error Handling

The system gracefully handles:

- API rate limit errors (pauses and retries)
- Network failures (retries up to 3 times)
- Invalid API keys (clear error messages)
- Empty or malformed transcripts (validation)
- Parsing failures (fallback to basic extraction)

### Innocence Score Calculation

The overall score (0-100) is calculated based on:

- **Explicit claims**: Up to 30 points
  - High confidence (>0.8): 30 points
  - Medium confidence (0.5-0.8): 20 points
  - Low confidence (<0.5): 10 points

- **Contextual signals**: Up to 25 points
  - Strong evidence (alibi, DNA): 25 points
  - Medium evidence (recantation): 15 points
  - Weak evidence (inconsistencies): 10 points

- **Implicit signals**: Up to 25 points
  - Multiple signals: 25 points
  - Single strong signal: 15 points
  - Weak signals: 10 points

- **Bias language**: Up to 20 points
  - Frequent bias patterns: 20 points
  - Moderate patterns: 12 points
  - Few patterns: 5 points

### Priority Scoring

Cases are ranked (0-100) for the AI Priority Picks sidebar:

- **Innocence claim strength**: 0-30 points (uses AI analysis)
- **Commissioner bias risk**: 0-25 points (panel composition)
- **Case urgency**: 0-25 points (hearing recency)
- **Assignment status**: 0-20 points (unassigned = higher priority)

**File**: `src/services/priority.ts`

## Troubleshooting

### AI Insights Not Loading

**Check:**
- `VITE_GEMINI_API_KEY` is set in `.env`
- API key is valid at [Google AI Studio](https://aistudio.google.com/apikey)
- Browser console for error messages
- Network tab for API call failures

**Solutions:**
- Verify API key has no extra spaces
- Check daily/monthly quota usage
- Wait 1 minute if rate limited

### "No Inmate Speech Found" Error

**Causes:**
- Transcript missing speaker labels
- Incorrect speaker label format
- Empty or corrupted transcript

**Solutions:**
- Check transcript has "INMATE:" or "DEFENDANT:" labels
- View browser console for diagnostic info
- Try uploading a different transcript

### Low Confidence Scores

**Causes:**
- Vague or indirect language in transcript
- Poor transcript quality (OCR errors)
- Limited inmate speech in the hearing

**Solutions:**
- Review the actual quotes (may still be valuable)
- Check PDF quality if uploaded from PDF
- Consider context even with lower confidence
